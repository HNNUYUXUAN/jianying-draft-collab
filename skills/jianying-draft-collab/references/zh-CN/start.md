# 中文接入

## SETUP-1

从实际技能安装位置运行 bootstrap，运行根可配置；已就绪的本机环境原位复用。配置只来自该运行根与进程环境，进程变量优先。先做只读 doctor，再按任务 preflight；真实本地、原生、云和 Chrome 能力分别验收。参考[环境](../environment.md)。

剪映优先使用用户已有可用版本。未知接口在本机隔离目录研究与试验，验证创建、读取、保存和重读后缓存对应能力；应用和适配器指纹改变则重验。参考[兼容](../compatibility.md)。

## RUN-1

按用户的片长、风格和交付目标策划；新增讲解图页走 Chrome“创建图片”。原创音乐先写主题、和声、结构和谱面，按实际旁白与字幕区间避让；也支持用户音频或无配乐。已有草稿从最后保存副本修订，保留未知字段、字幕、时间及原始文件。参考[制片](../video-workflow.md)、[音乐](../bgm.md)与[草稿](../draft.md)。

## CLOSE-1

交付导入包、可编辑草稿和完整预览；原生读取、完整解码及实际播放分开记录。用户导出后，归档真正的最终成片与最后保存版，检查引用及文件哈希，再清理本任务临时副本并标记完结。参考[归档](../storage-and-handoff.md)。
