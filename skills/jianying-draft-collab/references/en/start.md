# English onboarding

## SETUP-1

Resolve bootstrap from the actual skill folder and choose a runtime root. Reuse
verified local environments in place. Configuration comes from that runtime and
process variables, with the process taking precedence. Run read-only doctor and
task-specific preflight; verify real local, native, cloud and host Chrome
capabilities separately. See [environment details](../environment.md).

Keep the user's working editor version. Analyze changed interfaces in an isolated
local workspace, verify creation/read/save/reopen, then cache only the operations
proved on that device. App or adapter fingerprint changes require revalidation.
See [compatibility](../compatibility.md).

## RUN-1

Plan to the user's duration, style and deliverables. New explanatory image pages
use host Chrome ChatGPT Create image. Author a theme, harmony, form and score for
original music; protect narration using caption spans and actual audio activity.
User-provided audio and no-BGM modes are supported. Revise a complete copy of the
latest saved draft, preserving unknown fields, captions, timing and originals.
See [production](../video-workflow.md), [music](../bgm.md) and [drafts](../draft.md).

## CLOSE-1

Deliver import media, an editable draft and a complete preview. Record native
reads, complete decoding and actual playback separately. After user export,
archive the real final export and latest saved draft, validate references and
hashes, then clean only this task's archived temporary copies and mark it closed.
See [handoff](../storage-and-handoff.md).
