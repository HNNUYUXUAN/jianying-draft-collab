# Contributing

Keep changes focused on a reproducible workflow or an observed failure. Start
with the maintained skill in `skills/jianying-draft-collab` and read `AGENTS.md`.

Run the affected runtime tests and package validation before a pull request.
Add observable checks for changed media, install, cache or native semantics.
Keep real cloud and host-browser tests separate from offline unit tests.

Native compatibility fixes should describe the installed interface, required
capabilities and isolated read/write evidence. Do not submit application binaries,
private draft contents, proprietary keys or account data. A new version number
alone is not a compatibility test.

Update equivalent Chinese and English onboarding text. Generated README imagery
must be labelled as concept art; sample outputs must identify synthetic fixtures.
Keep third-party attribution and update locks and managed manifests when needed.

For issues, include OS/editor versions, the failed stage and redacted diagnostics.
Private settings and machine-specific paths can be replaced with placeholders.
