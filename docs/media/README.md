# Public media / 公开素材

`hero-zh.webp` and `hero-en.webp` are concept illustrations created in ChatGPT's
Chrome Create image interface on 2026-11-15. They portray an abstract film/music
workflow, not Jianying UI or experimental evidence. Original downloads and the
private generation records are retained by the maintainer. WebP derivatives use
aspect-preserving resize and encoding without semantic changes.

`demo.gif` and `demo.mp4` come from the actual 12-second key-free smoke
render in a new runtime directory. `music.mp3` is the full 40-second render of
`music-demo-score.json`. These use purpose-made public synthetic fixtures. The fixture's geometric motion and numerical activity
signal are labelled as tests, not a physical measurement or a human recording.
Music uses the original public score and selected CC0 VCSL/VSCO samples through
the pinned renderer. No personal experiment footage, textbook pages or saved
user drafts are included.

Original project sample code and assets are offered under the repository MIT
license to the extent the maintainer owns rights. The recordings retain CC0;
third-party tools retain their respective terms. The generated illustrations'
provenance is disclosed here without claiming exclusive rights.
